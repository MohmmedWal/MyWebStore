# متجر عطارد للعطور

موقع React مبني باستخدام Vite، ويعرض العطور من خلال وظيفة خادمية على Vercel. تبقى السلة وتفضيل الوضع الداكن/الفاتح محفوظين محليًا في المتصفح.

## التشغيل محليًا

1. ثبّت Node.js (الإصدار 20 أو أحدث).
2. ثبّت الاعتماديات:
   ```sh
   npm install
   ```
3. انسخ `.env.example` إلى `.env.local` وضع مفتاح RapidAPI الجديد في `RAPIDAPI_KEY`.
4. شغّل الموقع:
   ```sh
   npm run dev
   ```

خادم التطوير المحلي يمرّر `/api/perfumes` إلى الوظيفة نفسها المستخدمة على Vercel.

## النشر على Vercel

1. ارفع المشروع إلى مستودع Git.
2. من Vercel اختر **Add New Project** ثم اربط المستودع.
3. اترك إعدادات Vite الافتراضية؛ أمر البناء هو `npm run build` ومجلد الناتج `dist`.
4. من **Project Settings → Environment Variables** أضف:
   - الاسم: `RAPIDAPI_KEY`
   - القيمة: مفتاح RapidAPI جديد
   - البيئات: Production، وأي بيئة معاينة تحتاجها
5. أعد النشر بعد إضافة المتغير. وظيفة `/api/perfumes` تستخدم المفتاح على الخادم فقط؛ لا تضعه في متغير يبدأ بـ`VITE_`.

## قبل الإطلاق

- ألغِ مفتاح RapidAPI السابق وأنشئ مفتاحًا جديدًا؛ المفتاح السابق كان موجودًا في كود الواجهة ويمكن اعتباره مكشوفًا.
- تحقق من تفعيل اشتراك/حدود واجهة العطور في RapidAPI ومن أن المفتاح الجديد مخوّل للوصول إليها.
- نفّذ `npm run lint` و`npm run build` قبل النشر.
- السلة حاليًا قائمة محلية للمنتجات والكميات فقط؛ لا يوجد دفع إلكتروني أو أسعار أو إدارة طلبات/مخزون.
